# Overlay

Files here are copied over the ReactOS source tree before the build, keeping their paths.
For example `overlay/media/rapps/...` replaces `media/rapps/...`.

Use this for whole new files (wallpapers, our own apps, artwork). Use `patches/` for edits to
existing ReactOS code. Only add artwork we made ourselves or that's clearly licensed for reuse,
and never Microsoft files or artwork.
